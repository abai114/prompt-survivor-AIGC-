## **本项目使用ai制作**<br>
### 网址：https://abai114.github.io/prompt-survivor-AIGC-/
### 游戏简介
- 类幸存者游戏，游戏时长*3min+*<br>
- 使用wasd移动，自动攻击，升级输入提示词，匹配对应关键词后生成对应武器，同时，敌人也会根据关键词不断提升自己的抗性<br>
- 关键词库："火", "冰", "电", "毒", "护盾", "吸血", "爆炸", "环绕", "击退", "分裂", "弹射", "追踪", "穿透"，输入同义词也可以匹配到对应词条<br>
  单次词条上限4条，单次包含的词条越少，效果越强力<br>
- 随着游戏推进，地图会出现冲刺、咒术、包抄、次数盾、属性盾等不同类型的敌人，考验不同词条搭配
- 为了限制吸血词条强度，其具有单独的0.5倍率乘区，同时敌人吸血抗性至多增长到50%，其他属性抗性至多增长到75%（其实根本吃不满）
